**Problem**: ytl.yaml had `gateway: "7.140.x.1"` (dc-sim octet) but prefix `9.140.x.0/24`.
Nico-api crashed with DB constraint `gateway_within_network`.

**Hotfix on jaslinux**:
```bash

sed -i 's/gateway: "7\.140\.1\.1"/gateway: "9.140.1.1"/' ~/sites/ytl/ytl.yaml
sed -i 's/gateway: "7\.140\.2\.1"/gateway: "9.140.2.1"/' ~/sites/ytl/ytl.yaml
```

**Code fix**: committed in `0931807` — `create-new-site.py` now replaces gateway IPs.
