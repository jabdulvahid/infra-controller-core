# nico-simulation

Simulation-specific files for deploying Nico on a DC simulation cluster.

These files live in **claude-notes/dc-simulation/nico-simulation/** and are
**copied into {infra_controller_repo}/nico-simulation/** at build/deploy time
by the simulation tooling.  The infra-controller-core repo is never modified.

## Contents

| File | Purpose | Used by |
|---|---|---|
| `Dockerfile.runtime-sim` | Runtime container without fluent-bit (GPG key issue) | `build-nico-components.py` |
| `sim-values/*.yaml` | Generated Helm values for each chart | `deploy-nico-system.py` |
| `README.md` | This file | — |

## sim-values/

Generated by `generate-sim-values.py nico-sim.yaml`.
Do not edit manually — re-run the generator after changing nico-sim.yaml.

## How files get to infra-controller-core

`build-nico-components.py` copies `Dockerfile.runtime-sim` into
`{infra_controller_repo}/nico-simulation/` before running `docker build`,
then removes it afterwards.  No permanent changes to the nico repo.

`generate-sim-values.py` writes `sim-values/*.yaml` directly into
`{infra_controller_repo}/nico-simulation/sim-values/`.
These are gitignored in infra-controller-core (generated, not committed).
